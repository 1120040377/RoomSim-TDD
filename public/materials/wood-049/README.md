# Furniture veneer — ambientCG Wood049

- Original, unmodified 1K JPG Color, NormalGL and Roughness maps.
- Source coverage: approximately 0.8 × 0.8 metres; procedural material, not a scan.

Bundled locally so saved rooms do not depend on a third-party texture host.
UVs use metre-scaled geometry. All three maps receive the same repeat, rotation
and deterministic offset, with a restrained normal strength for finished veneer.
