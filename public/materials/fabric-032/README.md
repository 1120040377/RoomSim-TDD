# Fabric 032

Original unchanged 1K JPG Color, NormalGL and Roughness channels from
[ambientCG Fabric032](https://ambientcg.com/view?id=Fabric032).
Downloaded 2026-09-12 from https://ambientcg.com/get?file=Fabric032_1K-JPG.zip.

License: [CC0 1.0, ambientCG license statement](https://docs.ambientcg.com/license/).
Creation technique: **Approximation**, not a scanned PBR material.

The provider gives no physical dimensions. RoomSim uses a deliberately chosen
40 cm repeat with metre-based upholstery UVs, independent seeded offsets, shared
image sources and mipmapped sampling. Normal strength is restrained at 0.18.
No displacement map, tessellation, transmission or extra rendering pass.

These three files total 4,502,221 bytes. If uploaded as RGBA8 with full mipmaps,
the shared 1024² texture set is approximately 16 MiB, excluding driver overhead.
This is a budget estimate, not a measured GPU-memory reading.
