# Simulated woven throw

Repository-authored, offline Blender cloth simulation exported as static glTF.
No third-party image or model is embedded. Runtime reuses the project's fabric textures.

Source and provenance: `docs/asset-studies/draped-throw/README.md`.
Generator: `scripts/build-cloth-asset.py`.
Canonical fit: 150 × 200 cm bed, mattress top 45 cm. Other dimensions use procedural fallback.
5468 triangles, one mesh, 121644 bytes. No runtime cloth physics.

Only the GLB is needed at runtime; Blender source and tool binaries are not published.
