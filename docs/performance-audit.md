## 复现异步预编译裁剪状态不匹配（2026-09-12）

本地 r160 `WebGLRenderer.compile()` 直接调用 prepareMaterial/getProgram，未逐材质调用 clipping.setState；实际 setProgram 则会更新裁剪状态。WebGLPrograms 的缓存键包含 numClippingPlanes/numClipIntersection，因此直接compileAsync可等待一个与真实裁剪绘制不同的版本，不能据“异步编译已完成”判定首次绘制无编译。

新增 `scripts/check-clipped-compile.cjs`，仅诊断、未改Three源码或默认应用行为。先用MeshBasicMaterial轻量绘制建立同样的两平面裁剪状态，并保持实际屏幕/离屏目标，再对真实mesh执行compileAsync(mesh,camera,targetScene)。8组覆盖屏幕/离屏、交集/普通裁剪、带法线贴图+sheen的不透明Physical材质/双面透明Physical材质，均有6个点光源。未建立状态的对照首次正式绘制新增1个不透明program或2个透明program；建立状态的组全部新增0个。所有最终64×64像素差异0，实际非零颜色通道1971或3459，排除空白图假通过；KHR_parallel_shader_compile可用，无WebGL错误。

首次同序测试中对照正式绘制约75–128ms，建立状态后约0.6–3.2ms。随后加入交替先后顺序复测，结构性结果仍全部通过，但透明组先编译时异步等待约64–66ms、后测对照draw约9–10ms，体现跨context驱动缓存影响；不能据一次计时声称固定百分比或完整样板间提升。新证据明确下一步应匹配裁剪与输出目标后异步等待，而不是只继续细分同步绘制。

尚未覆盖样板间真实阴影图/AO法线变体、环境贴图、混合材质数组和退出期间异步编译的资源生命周期；不能直接接入默认准备流程，更不能宣称卡顿/参考质感目标完成。

## AO 状态比较去除每帧字符串序列化（2026-09-12）

`InteriorOcclusionPass` 复用 `ValueSnapshot` 双数值缓冲，替代每次渲染分配状态数组并 `join(',')`。剪裁平面直接读取 xyz，不再调用分配数组的 `toArray()`。相机、网格、材质、剪裁、尺寸与动态变形的原有失效条件保留；材质释放和格式切换仍强制失效，绘制抛错后也使快照失效，避免复用不完整结果。

`profile-occlusion-cache.cjs` 在完整 Chromium 内运行实际 AO pass、替换 GPU draw 为无操作，交替六轮，每种方式 720 个有效样本。序列化对照同样复用数组，因此只隔离字符串成本，不包含旧数组分配收益。500 mesh 的 CPU 中位约 0.30→0.10ms，P95 0.40→0.30ms；1000 mesh 中位 0.60→0.30ms，P95 0.90→0.60ms。浏览器约 0.1ms 计时粒度，100 mesh 数值路径的零中位只说明低于分辨率，不代表零成本。该基准不是真实样板间帧率或 GPU 耗时，不能解释或宣称解决约 200ms shader 编译卡顿。

- 本场景有 15 个可见点光源，当前没有按房间/距离限制参与光照的灯数；像素着色成本值得单独做开关对照。点光源目前不投影，不是 15 份立方体阴影开销。
- 渲染 DPR 上限为 2：相同 CSS 尺寸下像素数量可达到 DPR 1 的四倍。需要在用户实际显示器分辨率和缩放下测量，不能拿低分辨率结果验收。
- 家具现已增量更新：移动/旋转/离地调整复用对象和 GPU 资源，尺寸/颜色变化只重建受影响家具；未改动的柜门状态保留。地面、水电、灯光按各自数据是否变化更新。灯具数据变化仍重建灯光组，受影响家具尺寸/材质重建时其临时开合状态不保证保留；还需测量长时间连续编辑的实际帧时间与资源趋势。
- 精细阴影仍是额外后处理，只在俯瞰/装修模式可选开启。需要独立测试日夜、行走、开柜门、连续编辑及多次进入退出的帧时间与显存趋势。

## 复测入口

启动本地服务后运行 `node scripts/profile-walkthrough.cjs`。可配置 `ROOMSIM_URL`（含生产预览地址）、`ROOMSIM_DPR`、`ROOMSIM_BROWSER_CHANNEL`（例如 chrome）和 `ROOMSIM_HEADED=1`。有界面运行时会打开测试浏览器窗口，只在需要硬件实测时显式开启。

脚本会输出实际 WebGL 渲染器；即使选择了 Chrome，也应确认不是 SwiftShader 或其他软件后端。手动复现可在地址的 hash 前加入 `?profile=1`，浏览器控制台查看 `window.roomSimProfile` 最近 300 帧。正常无参数访问不保存性能记录。
